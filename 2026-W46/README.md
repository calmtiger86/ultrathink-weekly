## 이번 주 핵심 3가지

### 1. Google, 대화로 수정하는 15초 AI 영상 모델 공개

Google은 11월 5일 **Gemini Omni 1.2 Flash**를 공개했습니다. 한 번에 만들 수 있는 영상 길이가 기존 10초에서 15초로 늘었고, 제품·배경·조명·날씨·화면 비율 등을 대화로 이어서 수정할 수 있습니다. Google은 이전 버전보다 가격을 30% 낮췄으며 Gemini API, Google Vids, 기업용 Gemini에서 제공한다고 밝혔습니다.[2]

**비개발자에게 의미하는 것**: 짧은 제품 소개나 소셜 영상의 초안을 만들고 수정하는 과정이 전문 편집 도구 중심에서 자연어 대화 중심으로 바뀌고 있습니다. 다만 바로 게시하기보다 로고·문구·인물 표현이 브랜드 기준과 저작권 원칙에 맞는지 사람이 마지막에 확인하는 절차가 필요합니다.

### 2. OpenAI, 취약점을 찾고 검증하는 GPT-6 Cyber 발표

OpenAI는 11월 5일 보안 연구용 모델 **GPT-6 Cyber**를 발표했습니다. 회사 발표에 따르면 이 모델은 허가된 범위 안에서 소프트웨어 취약점을 찾고 실제 악용 가능성을 검증하도록 훈련됐으며, 연구 과정에서 Firefox의 새로운 고위험 취약점 81건을 찾고 Linux 커널 취약점 948건에 대한 작동 가능한 익스플로잇을 개발하는 데 사용됐습니다. 초기에는 승인된 Daybreak Red 고객에게 제한적으로 제공됩니다.[1]

**비개발자에게 의미하는 것**: AI가 문서 작성뿐 아니라 보안 결함을 찾아내는 일에도 본격적으로 투입되고 있습니다. 회사에서 쓰는 SaaS나 업무 도구를 고를 때는 “AI 기능이 있는가”뿐 아니라 보안 업데이트 속도, 취약점 신고 절차, 고위험 작업에 대한 사람의 승인 체계까지 함께 확인해야 합니다.

### 3. Microsoft Copilot의 Claude, EU 역내 데이터 처리 지원 예정

Microsoft는 11월 5일 Copilot에서 제공하는 Anthropic의 Claude 모델을 **EU Data Boundary** 안으로 가져오겠다고 발표했습니다. 2026년 말까지 EU와 유럽자유무역연합(EFTA) 조직은 Copilot Cowork를 포함한 Copilot 환경에서 Claude를 쓰면서 데이터를 EU 경계 안에서 처리할 수 있게 됩니다. Microsoft는 고객 데이터가 생성형 AI 기반 모델 학습에 사용되지 않고, 관리자가 Claude 사용 권한을 정할 수 있다고 설명했습니다.[3]

**비개발자에게 의미하는 것**: 기업용 AI 선택 기준이 모델 성능만이 아니라 데이터가 어느 지역에서 처리되는지, 학습에 재사용되는지, 관리자가 권한을 통제할 수 있는지로 넓어지고 있습니다. 한국 조직은 이 발표가 EU·EFTA 대상이라는 점을 구분하고, 계약 전에 자사 계정에 실제 적용되는 데이터 저장·처리 지역과 관리 옵션을 확인해야 합니다.
